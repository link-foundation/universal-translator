# Requirements and verification for issue 1

This inventory lists every requirement from
[issue 1](https://github.com/link-foundation/universal-translator/issues/1) and
the review comments in
[PR 5](https://github.com/link-foundation/universal-translator/pull/5). The
[latest review](https://github.com/link-foundation/universal-translator/pull/5#issuecomment-7137697837)
asked for these things:

- A real grammar- and rule-based foundation instead of templates.
- Readable code.
- A common library that only smooths over standard-library differences.

So the translator was rebuilt around a parser, a meta language and rule
layers.

## Assumptions

- Hello World Collection and Rosetta Code are the source of the tasks. The
  examples are crafted versions of hello world, factorial, greatest common
  divisor, FizzBuzz and sum of squares, written so that they translate
  naturally. This is what the issue asks for ("if any examples are missing
  in original we craft them perfectly").
- Machine targets work with 64-bit integers and printed text. Other values
  are rejected with a clear error instead of being translated incorrectly.
- Proving equivalence and translating standard libraries are listed in the
  issue as future work. Here equivalence is checked by running the programs
  natively and by comparing meta programs (`sameMeaning`).
