# Requirements and verification for issue 6

This inventory lists every requirement from
[issue 6](https://github.com/link-foundation/universal-translator/issues/6).
The issue has no comments.
[PR 7](https://github.com/link-foundation/universal-translator/pull/7) has
one review comment from CodeQL, and one request from its author: resolve the
conflicts with `main` (which gained partial translation, language detection
and rules as data from issue 8) and make sure every requirement of every
issue is delivered everywhere (row 19). The issue 8 requirements are now
checked by the same gate, from
[their own inventory](../issue-8/requirements.lino). The machine-readable copy is
[requirements.lino](requirements.lino). `scripts/check-requirements.mjs`
reads it together with the
[issue 1 inventory](../issue-1/requirements.lino). The script runs in CI and
in `js/tests/requirements.test.js`, and fails unless every entry is done or
blocked with a stated reason.

## Blocked

These issue 1 requirements are still not met. They are reported as blocked,
not as done:

- **All Rosetta Code algorithm types** (`rosetta-algorithm-types`). Floating
  point, strings as values, higher-order functions, data structures, input
  and output, objects and concurrency all need values and statements the
  meta language does not have yet. See
  [rosetta-coverage.lino](../issue-1/rosetta-coverage.lino).
- **Classes as fragments** (`class-fragments`). Without objects in the meta
  language, a class has no meaning to translate.

Each needs a meta language extension that would have to go through all 30+
programming languages, the machine targets and the natural languages. That is
far bigger than a fix and is left for its own issue.

## Found while checking symmetry

- The comment directly above the first function used to become a file
  comment, so it moved away from the function. It now stays with the
  function.
- Programs whose functions had no empty line between them gained one in
  every translation. Fortran, Ada, Visual Basic and MATLAB also lost the
  empty line that was there.
- Perl and Bash read a function that returns `1` back as returning `true`,
  even when nothing used the result as a truth value.
- Every word of a vocabulary is checked to make sure that changing it
  changes the output. The words a language cannot show in a program are
  listed explicitly in `js/tests/vocabulary-effect.test.js`.
