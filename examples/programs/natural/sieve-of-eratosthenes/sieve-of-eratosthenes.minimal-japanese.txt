上限 が ある、 それ は 100 だ。
判定-素数 が ある、 それ は 1 の よう な もの (上限 足す 1) 個 だ。
この 後 判定-素数 の 部分 0 は 0 だ。
この 後 判定-素数 の 部分 1 は 0 だ。
全て の 数_ について 2 から 上限 まで これ を する：
  もし 判定-素数 の 部分 数_ が 1 と 同じ なら これ を する：
    数_ を 一つ の 行 に 言う。
    倍数 が ある、 それ は 数_ 掛ける 数_ だ。
    倍数 が 上限 より 多く ない の 間 これ を 何度 も する：
      この 後 判定-素数 の 部分 倍数 は 0 だ。
      この 後 倍数 は 倍数 足す 数_ だ。
