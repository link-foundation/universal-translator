Note: Fibonacci sequence in JavaScript, computed iteratively

Rule fibonacci with count is defined as follows:
  It is obligatory that previous is initially 0.
  It is obligatory that current is initially 1.
  For each step from 0 to count minus 1 the following applies:
    It is obligatory that next is initially previous plus current.
    It is obligatory that previous becomes current.
    It is obligatory that current becomes next.
  It is obligatory that the result is previous.

For each index from 0 to 20 the following applies:
  It is obligatory that the output shows “fibonacci(” followed by index followed by “) = ” followed by fibonacci of (index) as a line.
