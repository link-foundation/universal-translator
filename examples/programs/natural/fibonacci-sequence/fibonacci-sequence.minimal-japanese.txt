注：Fibonacci sequence in JavaScript, computed iteratively

誰か が フィボナッチ を 個数 で こう する：
  前 が ある、 それ は 0 だ。
  現在 が ある、 それ は 1 だ。
  全て の 段 について 0 から 個数 引く 1 まで これ を する：
    次 が ある、 それ は 前 足す 現在 だ。
    この 後 前 は 現在 だ。
    この 後 現在 は 次 だ。
  答え は 前 だ。

全て の 添字 について 0 から 20 まで これ を する：
  「fibonacci(」 それから 添字 それから 「) = 」 それから フィボナッチ (添字) を 一つ の 行 に 言う。
