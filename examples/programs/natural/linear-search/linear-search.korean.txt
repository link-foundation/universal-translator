참고: Linear search in JavaScript: find the position of a value in a list

수들 을 값 목록 (31, 41, 59, 26, 53, 58, 97, 93) 로 만든다.
Wanted 을 값 53 로 만든다.
위치 을 값 -1 로 만든다.
현재 을 값 0 로 만든다.
각 색인 에 대해 0 부터 수들 길이 빼기 1 까지 다음을 반복한다:
  수 을 값 수들 원소 색인 로 만든다.
  만약 수 이 wanted 과 같음 그리고 위치 이 0 보다 작음 이면 다음을 한다:
    위치 을 현재 로 바꾼다.
  현재 을 현재 더하기 1 로 바꾼다.
“Found ” 뒤에 wanted 뒤에 “ at position ” 뒤에 위치 을 쓰고 줄을 바꾼다.
