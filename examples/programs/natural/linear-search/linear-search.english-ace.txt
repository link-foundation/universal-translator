Note: Linear search in JavaScript: find the position of a value in a list

There is a variable numbers whose value is the list (31, 41, 59, 26, 53, 58, 97, 93).
There is a variable wanted whose value is 53.
There is a variable position whose value is -1.
There is a variable current whose value is 0.
For every number in numbers the program does the following:
  If number is equal to wanted and position is less than 0 then the program does the following:
    The value of position becomes current.
  The value of current becomes current plus 1.
The program writes a line that contains “Found ” followed by wanted followed by “ at position ” followed by position.
