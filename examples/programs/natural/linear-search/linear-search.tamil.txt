குறிப்பு: Linear search in JavaScript: find the position of a value in a list

எண்கள் ஐ மதிப்பு பட்டியல் (31, 41, 59, 26, 53, 58, 97, 93) உடன் உருவாக்கு.
Wanted ஐ மதிப்பு 53 உடன் உருவாக்கு.
நிலை ஐ மதிப்பு -1 உடன் உருவாக்கு.
தற்போதைய ஐ மதிப்பு 0 உடன் உருவாக்கு.
ஒவ்வொரு சுட்டெண் க்கும் 0 முதல் எண்கள் நீளம் கழித்தல் 1 வரை இதை மீண்டும் செய்:
  எண் ஐ மதிப்பு எண்கள் இல் உறுப்பு சுட்டெண் உடன் உருவாக்கு.
  ஒருவேளை எண் மதிப்பு wanted க்கு சமம் மற்றும் நிலை மதிப்பு 0 ஐ விட குறைவு என்றால் இதைச் செய்:
    நிலை ஐ தற்போதைய ஆக மாற்று.
  தற்போதைய ஐ தற்போதைய கூட்டல் 1 ஆக மாற்று.
“Found ” அதன் பின் wanted அதன் பின் “ at position ” அதன் பின் நிலை எழுதி வரியை முடி.
