નોંધ: Linear search in JavaScript: find the position of a value in a list

સંખ્યાઓ ને કિંમત યાદી (31, 41, 59, 26, 53, 58, 97, 93) સાથે બનાવો.
Wanted ને કિંમત 53 સાથે બનાવો.
સ્થાન ને કિંમત -1 સાથે બનાવો.
વર્તમાન ને કિંમત 0 સાથે બનાવો.
દરેક અનુક્રમ માટે 0 થી સંખ્યાઓ ની લંબાઈ ઓછા 1 સુધી આ ફરી કરો:
  સંખ્યા ને કિંમત સંખ્યાઓ માં ઘટક અનુક્રમ સાથે બનાવો.
  જો સંખ્યા નું મૂલ્ય wanted બરાબર છે અને સ્થાન નું મૂલ્ય 0 કરતાં ઓછું છે તો આ કરો:
    સ્થાન ને વર્તમાન માં બદલો.
  વર્તમાન ને વર્તમાન વત્તા 1 માં બદલો.
“Found ” પછી wanted પછી “ at position ” પછી સ્થાન લખો અને લીટી પૂરી કરો.
