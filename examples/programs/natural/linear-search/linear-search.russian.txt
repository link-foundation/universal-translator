Примечание: Linear search in JavaScript: find the position of a value in a list

Создать числа со значением список (31, 41, 59, 26, 53, 58, 97, 93).
Создать wanted со значением 53.
Создать позиция со значением -1.
Создать текущий со значением 0.
Для каждого индекс от 0 до длина числа минус 1 повторять это:
  Создать число со значением элемент индекс списка числа.
  Если число равно wanted и позиция меньше 0, сделать это:
    Изменить позиция на текущий.
  Изменить текущий на текущий плюс 1.
Написать «Found » затем wanted затем « at position » затем позиция и закончить строку.
