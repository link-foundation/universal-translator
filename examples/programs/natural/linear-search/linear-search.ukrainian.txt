Примітка: Linear search in JavaScript: find the position of a value in a list

Створити числа зі значенням список (31, 41, 59, 26, 53, 58, 97, 93).
Створити wanted зі значенням 53.
Створити позиція зі значенням -1.
Створити поточний зі значенням 0.
Для кожного індекс від 0 до довжина числа мінус 1 повторювати це:
  Створити число зі значенням елемент індекс списку числа.
  Якщо число дорівнює wanted і позиція менше за 0, зробити це:
    Змінити позиція на поточний.
  Змінити поточний на поточний плюс 1.
Написати «Found » потім wanted потім « at position » потім позиція і завершити рядок.
