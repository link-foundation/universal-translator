નોંધ: Linear search in JavaScript: find the position of a value in a list

સંખ્યાઓ છે, તે આ વસ્તુઓ (31, 41, 59, 26, 53, 58, 97, 93) છે.
Wanted છે, તે 53 છે.
સ્થાન છે, તે -1 છે.
વર્તમાન છે, તે 0 છે.
દરેક અનુક્રમ માટે 0 થી સંખ્યાઓ માં કેટલા ભાગ ઓછા 1 સુધી આ કરો:
  સંખ્યા છે, તે સંખ્યાઓ માં ભાગ અનુક્રમ છે.
  જો સંખ્યા એ wanted જેવું જ છે અને સ્થાન એ 0 કરતાં ઓછું છે તો આ કરો:
    આ પછી સ્થાન વર્તમાન છે.
  આ પછી વર્તમાન વર્તમાન વત્તા 1 છે.
“Found ” પછી wanted પછી “ at position ” પછી સ્થાન એક લીટીમાં કહો.
