Note: Linear search in JavaScript: find the position of a value in a list

Set numbers to the list (31, 41, 59, 26, 53, 58, 97, 93).
Set wanted to 53.
Set position to -1.
Set current to 0.
For each number in numbers, do these steps:
  If number equals wanted and position is less than 0, do these steps:
    Change position to current.
  Change current to current plus 1.
Write line “Found ” then wanted then “ at position ” then position.
