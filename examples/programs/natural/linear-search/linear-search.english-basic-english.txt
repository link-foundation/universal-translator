Note: Linear search in JavaScript: find the position of a value in a list

Let numbers be the list (31, 41, 59, 26, 53, 58, 97, 93).
Let wanted be 53.
Let position be -1.
Let current be 0.
For every number in numbers, do this:
  If number is wanted and position is under 0, do this:
    Let position now be current.
  Let current now be current plus 1.
Say “Found ” then wanted then “ at position ” then position and end the line.
