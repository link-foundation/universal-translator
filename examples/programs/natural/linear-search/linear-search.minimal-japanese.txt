注：Linear search in JavaScript: find the position of a value in a list

数列 が ある、 それ は これら の もの (31、 41、 59、 26、 53、 58、 97、 93) だ。
Wanted が ある、 それ は 53 だ。
位置 が ある、 それ は -1 だ。
現在 が ある、 それ は 0 だ。
全て の 添字 について 0 から 数列 の 部分 の 数 引く 1 まで これ を する：
  数_ が ある、 それ は 数列 の 部分 添字 だ。
  もし 数_ が wanted と 同じ かつ 位置 が 0 より 少ない なら これ を する：
    この 後 位置 は 現在 だ。
  この 後 現在 は 現在 足す 1 だ。
「Found 」 それから wanted それから 「 at position 」 それから 位置 を 一つ の 行 に 言う。
