نوٹ: Linear search in JavaScript: find the position of a value in a list

ایک اعداد ہے، یہ ہے یہ چیزیں (31، 41، 59، 26، 53، 58، 97، 93)۔
ایک wanted ہے، یہ ہے 53۔
ایک مقام ہے، یہ ہے -1۔
ایک موجودہ ہے، یہ ہے 0۔
ہر اشاریہ کے لیے 0 سے اعداد میں کتنے حصے ہیں تفریق 1 تک یہ کریں:
  ایک عدد ہے، یہ ہے اعداد کا حصہ اشاریہ۔
  اگر عدد وہی ہے جو wanted ہے اور مقام 0 سے کم ہے تو یہ کریں:
    اس کے بعد مقام اب موجودہ ہے۔
  اس کے بعد موجودہ اب موجودہ جمع 1 ہے۔
“Found ” پھر wanted پھر “ at position ” پھر مقام ایک سطر میں کہیں۔
