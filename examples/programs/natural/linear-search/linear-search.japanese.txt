注：Linear search in JavaScript: find the position of a value in a list

数列 を 値 リスト (31、 41、 59、 26、 53、 58、 97、 93) で 作る。
Wanted を 値 53 で 作る。
位置 を 値 -1 で 作る。
現在 を 値 0 で 作る。
添字 を 0 から 数列 の 長さ 引く 1 まで 数えて 次 を 繰り返す：
  数 を 値 数列 の 要素 添字 で 作る。
  もし 数 が wanted に 等しい かつ 位置 が 0 より 小さい なら 次 を する：
    位置 を 現在 に 変える。
  現在 を 現在 足す 1 に 変える。
「Found 」 に 続けて wanted に 続けて 「 at position 」 に 続けて 位置 を 書いて 改行 する。
