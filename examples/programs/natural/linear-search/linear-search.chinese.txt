注：Linear search in JavaScript: find the position of a value in a list

创建 数列 值 为 列表 (31， 41， 59， 26， 53， 58， 97， 93)。
创建 wanted 值 为 53。
创建 位置 值 为 -1。
创建 当前 值 为 0。
对 每个 索引 从 0 到 数列 长度 减 1 重复 这些：
  创建 数 值 为 数列 第 索引 项。
  如果 数 等于 wanted 并且 位置 小于 0 就 做 这些：
    把 位置 改 为 当前。
  把 当前 改 为 当前 加 1。
输出 “Found ” 接 wanted 接 “ at position ” 接 位置 并 换行。
