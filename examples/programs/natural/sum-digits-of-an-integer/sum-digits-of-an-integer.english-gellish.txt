Note: Sum digits of an integer in JavaScript

Sum-of-digits is defined as a procedure with input number:
  Total is classified as a variable with initial value 0.
  While number is greater than 0 the following is repeated:
    Total has as new value total plus number modulo 10.
    Number has as new value number divided by 10.
  The procedure has as result total.

The output has as next line “The digits of 1234567890 sum to ” concatenated with sum-of-digits applied to (1234567890).
