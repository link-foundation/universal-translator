Note: Sum digits of an integer in JavaScript

Here is how to work out sum-of-digits from number:
  Let total start as 0.
  As long as number is more than 0, keep doing this:
    Set total to total plus number modulo 10.
    Set number to number divided by 10.
  The answer is total.
