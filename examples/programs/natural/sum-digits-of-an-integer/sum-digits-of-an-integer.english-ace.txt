Note: Sum digits of an integer in JavaScript

The procedure sum-of-digits takes number:
  There is a variable total whose value is 0.
  While number is greater than 0 the program repeats the following:
    The value of total becomes total plus number modulo 10.
    The value of number becomes number divided by 10.
  The procedure returns total.

The program writes a line that contains “The digits of 1234567890 sum to ” followed by sum-of-digits of (1234567890).
