Note: Primality by trial division in JavaScript

Is-prime is defined as a procedure with input number:
  If number is less than 2 then the following is performed:
    The procedure has as result false.
  Divisor is classified as a variable with initial value 2.
  While divisor times divisor is at most number the following is repeated:
    If number modulo divisor is equal to 0 then the following is performed:
      The procedure has as result false.
    Divisor has as new value divisor plus 1.
  The procedure has as result true.

For each number from 1 to 50 the following is repeated:
  If is-prime applied to (number) then the following is performed:
    The output has as next line number.
