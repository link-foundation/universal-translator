Note: Primality by trial division in JavaScript

Rule is-prime with number is defined as follows:
  If number is less than 2 then the following applies:
    It is obligatory that the result is false.
  It is obligatory that divisor is initially 2.
  As long as divisor times divisor is at most number the following applies repeatedly:
    If number modulo divisor is equal to 0 then the following applies:
      It is obligatory that the result is false.
    It is obligatory that divisor becomes divisor plus 1.
  It is obligatory that the result is true.

For each number from 1 to 50 the following applies:
  If is-prime of (number) then the following applies:
    It is obligatory that the output shows number as a line.
