注：Primality by trial division in JavaScript

誰か が 判定-素数 を 数_ で こう する：
  もし 数_ が 2 より 少ない なら これ を する：
    答え は 偽 だ。
  約数 が ある、 それ は 2 だ。
  約数 掛ける 約数 が 数_ より 多く ない の 間 これ を 何度 も する：
    もし 数_ 剰余 約数 が 0 と 同じ なら これ を する：
      答え は 偽 だ。
    この 後 約数 は 約数 足す 1 だ。
  答え は 真 だ。

全て の 数_ について 1 から 50 まで これ を する：
  もし 判定-素数 (数_) なら これ を する：
    数_ を 一つ の 行 に 言う。
