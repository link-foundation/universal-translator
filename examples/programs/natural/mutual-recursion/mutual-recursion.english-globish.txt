Note: Mutual recursion in JavaScript: the Hofstadter Female and Male sequences

To get female from index, do this:
  If index equals 0, do this:
    Return 1.
  Return index minus male of (female of (index minus 1)).

To get male from index, do this:
  If index equals 0, do this:
    Return 0.
  Return index minus female of (male of (index minus 1)).

For each index from 0 to 19, do this:
  Say index then “: ” then female of (index) then “ ” then male of (index) on a line.
