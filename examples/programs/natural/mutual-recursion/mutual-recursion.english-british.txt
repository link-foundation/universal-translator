Note: Mutual recursion in JavaScript: the Hofstadter Female and Male sequences

Define female using index:
  If index equals 0, do this:
    Give back 1.
  Give back index minus male of (female of (index minus 1)).

Define male using index:
  If index equals 0, do this:
    Give back 0.
  Give back index minus female of (male of (index minus 1)).

For each index from 0 to 19, repeat this:
  Write index followed by ‘: ’ followed by female of (index) followed by ‘ ’ followed by male of (index) and end the line.
