注：Mutual recursion in JavaScript: the Hofstadter Female and Male sequences

誰か が 女性 を 添字 で こう する：
  もし 添字 が 0 と 同じ なら これ を する：
    答え は 1 だ。
  答え は 添字 引く 男性 (女性 (添字 引く 1)) だ。

誰か が 男性 を 添字 で こう する：
  もし 添字 が 0 と 同じ なら これ を する：
    答え は 0 だ。
  答え は 添字 引く 女性 (男性 (添字 引く 1)) だ。

全て の 添字 について 0 から 19 まで これ を する：
  添字 それから 「: 」 それから 女性 (添字) それから 「 」 それから 男性 (添字) を 一つ の 行 に 言う。
