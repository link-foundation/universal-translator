Note: Mutual recursion in JavaScript: the Hofstadter Female and Male sequences

The procedure female takes index:
  If index is equal to 0 then the program does the following:
    The procedure returns 1.
  The procedure returns index minus male of (female of (index minus 1)).

The procedure male takes index:
  If index is equal to 0 then the program does the following:
    The procedure returns 0.
  The procedure returns index minus female of (male of (index minus 1)).

For every index from 0 to 19 the program does the following:
  The program writes a line that contains index followed by “: ” followed by female of (index) followed by “ ” followed by male of (index).
