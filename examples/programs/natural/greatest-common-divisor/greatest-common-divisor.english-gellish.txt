Note: Greatest common divisor in JavaScript, using the Euclidean algorithm

Greatest-common-divisor is defined as a procedure with input first and second:
  While second is not equal to 0 the following is repeated:
    Remainder is classified as a variable with initial value first modulo second.
    First has as new value second.
    Second has as new value remainder.
  The procedure has as result first.

The output has as next line “The greatest common divisor of 1071 and 462 is ” concatenated with greatest-common-divisor applied to (1071, 462).
