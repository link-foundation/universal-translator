குறிப்பு: Ackermann function in JavaScript, defined recursively

யாரோ அக்கர்மன் ஐ முதலாவது மற்றும் இரண்டாவது கொண்டு இப்படிச் செய்கிறார்:
  முதலாவது உம் 0 உம் ஒன்றே என்றால் இதைச் செய்:
    பதில் இரண்டாவது கூட்டல் 1.
  இரண்டாவது உம் 0 உம் ஒன்றே என்றால் இதைச் செய்:
    பதில் அக்கர்மன் (முதலாவது கழித்தல் 1, 1).
  பதில் அக்கர்மன் (முதலாவது கழித்தல் 1, அக்கர்மன் (முதலாவது, இரண்டாவது கழித்தல் 1)).

எல்லா முதலாவது க்கும் 0 முதல் 3 வரை இதைச் செய்:
  எல்லா இரண்டாவது க்கும் 0 முதல் 4 வரை இதைச் செய்:
    “ackermann(” அதன் பின் முதலாவது அதன் பின் “, ” அதன் பின் இரண்டாவது அதன் பின் “) = ” அதன் பின் அக்கர்மன் (முதலாவது, இரண்டாவது) ஐ ஒரு வரியில் சொல்.
