某人 这样 用 第一 和 第二 做 阿克曼：
  如果 第一 跟 0 一样 就 做 这个：
    答案 是 第二 加 1。
  如果 第二 跟 0 一样 就 做 这个：
    答案 是 阿克曼 (第一 减 1， 1)。
  答案 是 阿克曼 (第一 减 1， 阿克曼 (第一， 第二 减 1))。

对 所有 第一 从 0 到 3 做 这个：
  对 所有 第二 从 0 到 4 做 这个：
    说 “ackermann(” 然后 第一 然后 “, ” 然后 第二 然后 “) = ” 然后 阿克曼 (第一， 第二) 在 一 行 上。
