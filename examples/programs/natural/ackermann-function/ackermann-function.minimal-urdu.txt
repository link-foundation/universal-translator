نوٹ: Ackermann function in JavaScript, defined recursively

  اگر پہلا وہی ہے جو 0 ہے تو یہ کریں:
    جواب ہے دوسرا جمع 1۔
  اگر دوسرا وہی ہے جو 0 ہے تو یہ کریں:
    جواب ہے ایکرمین (پہلا تفریق 1، 1)۔
  جواب ہے ایکرمین (پہلا تفریق 1، ایکرمین (پہلا، دوسرا تفریق 1))۔

ہر پہلا کے لیے 0 سے 3 تک یہ کریں:
  ہر دوسرا کے لیے 0 سے 4 تک یہ کریں:
