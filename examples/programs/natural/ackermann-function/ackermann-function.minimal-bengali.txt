টীকা: Ackermann function in JavaScript, defined recursively

কেউ প্রথম ও দ্বিতীয় দিয়ে এভাবে আকারম্যান করে:
  যদি প্রথম আর 0 একই তবে এটা করো:
    উত্তর হলো দ্বিতীয় যোগ 1।
  যদি দ্বিতীয় আর 0 একই তবে এটা করো:
    উত্তর হলো আকারম্যান (প্রথম বিয়োগ 1, 1)।
  উত্তর হলো আকারম্যান (প্রথম বিয়োগ 1, আকারম্যান (প্রথম, দ্বিতীয় বিয়োগ 1))।

প্রতিটি প্রথম এর জন্য 0 থেকে 3 পর্যন্ত এটা করো:
  প্রতিটি দ্বিতীয় এর জন্য 0 থেকে 4 পর্যন্ত এটা করো:
    “ackermann(” তারপর প্রথম তারপর “, ” তারপর দ্বিতীয় তারপর “) = ” তারপর আকারম্যান (প্রথম, দ্বিতীয়) এক লাইনে বলো।
