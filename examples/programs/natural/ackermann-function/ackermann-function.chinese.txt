注：Ackermann function in JavaScript, defined recursively

定义 阿克曼 使用 第一 和 第二：
  如果 第一 等于 0 就 做 这些：
    返回 第二 加 1。
  如果 第二 等于 0 就 做 这些：
    返回 阿克曼 (第一 减 1， 1)。
  返回 阿克曼 (第一 减 1， 阿克曼 (第一， 第二 减 1))。

对 每个 第一 从 0 到 3 重复 这些：
  对 每个 第二 从 0 到 4 重复 这些：
    输出 “ackermann(” 接 第一 接 “, ” 接 第二 接 “) = ” 接 阿克曼 (第一， 第二) 并 换行。
