آکرمن را با نخستین و دومین تعریف کن:
  اگر نخستین برابر 0 است آنگاه این را انجام بده:
    دومین بعلاوه 1 را برگردان.
  اگر دومین برابر 0 است آنگاه این را انجام بده:
    آکرمن (نخستین منهای 1، 1) را برگردان.
  آکرمن (نخستین منهای 1، آکرمن (نخستین، دومین منهای 1)) را برگردان.

برای هر نخستین از 0 تا 3 این را تکرار کن:
  برای هر دومین از 0 تا 4 این را تکرار کن:
    «ackermann(» سپس نخستین سپس «, » سپس دومین سپس «) = » سپس آکرمن (نخستین، دومین) را بنویس و سطر را تمام کن.
