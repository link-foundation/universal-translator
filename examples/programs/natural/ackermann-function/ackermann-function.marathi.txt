टीप: Ackermann function in JavaScript, defined recursively

एकरमन ची व्याख्या पहिला आणि दुसरा वापरून करा:
  जर पहिला चे मूल्य 0 इतके आहे तर हे करा:
    दुसरा अधिक 1 परत द्या.
  जर दुसरा चे मूल्य 0 इतके आहे तर हे करा:
    एकरमन (पहिला वजा 1, 1) परत द्या.
  एकरमन (पहिला वजा 1, एकरमन (पहिला, दुसरा वजा 1)) परत द्या.

प्रत्येक पहिला साठी 0 पासून 3 पर्यंत हे पुन्हा करा:
  प्रत्येक दुसरा साठी 0 पासून 4 पर्यंत हे पुन्हा करा:
    “ackermann(” नंतर पहिला नंतर “, ” नंतर दुसरा नंतर “) = ” नंतर एकरमन (पहिला, दुसरा) लिहा आणि ओळ संपवा.
