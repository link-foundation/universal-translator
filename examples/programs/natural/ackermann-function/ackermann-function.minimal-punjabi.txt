ਨੋਟ: Ackermann function in JavaScript, defined recursively

ਕੋਈ ਐਕਰਮੈਨ ਨੂੰ ਪਹਿਲਾ ਅਤੇ ਦੂਜਾ ਨਾਲ ਇਸ ਤਰ੍ਹਾਂ ਕਰਦਾ ਹੈ:
  ਜੇ ਪਹਿਲਾ 0 ਵਰਗਾ ਹੀ ਹੈ ਤਾਂ ਇਹ ਕਰੋ:
    ਜਵਾਬ ਦੂਜਾ ਜਮ੍ਹਾਂ 1 ਹੈ।
  ਜੇ ਦੂਜਾ 0 ਵਰਗਾ ਹੀ ਹੈ ਤਾਂ ਇਹ ਕਰੋ:
    ਜਵਾਬ ਐਕਰਮੈਨ (ਪਹਿਲਾ ਘਟਾਓ 1, 1) ਹੈ।
  ਜਵਾਬ ਐਕਰਮੈਨ (ਪਹਿਲਾ ਘਟਾਓ 1, ਐਕਰਮੈਨ (ਪਹਿਲਾ, ਦੂਜਾ ਘਟਾਓ 1)) ਹੈ।

ਹਰ ਪਹਿਲਾ ਲਈ 0 ਤੋਂ 3 ਤੱਕ ਇਹ ਕਰੋ:
  ਹਰ ਦੂਜਾ ਲਈ 0 ਤੋਂ 4 ਤੱਕ ਇਹ ਕਰੋ:
    “ackermann(” ਤੋਂ ਬਾਅਦ ਪਹਿਲਾ ਤੋਂ ਬਾਅਦ “, ” ਤੋਂ ਬਾਅਦ ਦੂਜਾ ਤੋਂ ਬਾਅਦ “) = ” ਤੋਂ ਬਾਅਦ ਐਕਰਮੈਨ (ਪਹਿਲਾ, ਦੂਜਾ) ਇੱਕ ਸਤਰ ਵਿੱਚ ਕਹੋ।
