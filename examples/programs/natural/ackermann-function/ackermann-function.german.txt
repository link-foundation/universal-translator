Hinweis: Ackermann function in JavaScript, defined recursively

Definiere Ackermann mit erste und zweite:
  Wenn erste ist gleich 0, tue dies:
    Gib zweite plus 1 zurück.
  Wenn zweite ist gleich 0, tue dies:
    Gib Ackermann von (erste minus 1, 1) zurück.
  Gib Ackermann von (erste minus 1, Ackermann von (erste, zweite minus 1)) zurück.
