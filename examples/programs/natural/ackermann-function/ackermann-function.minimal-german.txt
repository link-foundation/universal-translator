Hinweis: Ackermann function in JavaScript, defined recursively

So tut jemand Ackermann mit erste und zweite:
  Wenn erste ist dasselbe wie 0, tue dies:
    Die Antwort ist zweite plus 1.
  Wenn zweite ist dasselbe wie 0, tue dies:
    Die Antwort ist Ackermann von (erste minus 1, 1).
  Die Antwort ist Ackermann von (erste minus 1, Ackermann von (erste, zweite minus 1)).
