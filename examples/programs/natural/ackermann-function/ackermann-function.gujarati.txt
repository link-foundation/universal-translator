નોંધ: Ackermann function in JavaScript, defined recursively

એકરમેન ને પ્રથમ અને બીજું વડે વ્યાખ્યાયિત કરો:
  જો પ્રથમ નું મૂલ્ય 0 બરાબર છે તો આ કરો:
    બીજું વત્તા 1 પાછું આપો.
  જો બીજું નું મૂલ્ય 0 બરાબર છે તો આ કરો:
    એકરમેન (પ્રથમ ઓછા 1, 1) પાછું આપો.
  એકરમેન (પ્રથમ ઓછા 1, એકરમેન (પ્રથમ, બીજું ઓછા 1)) પાછું આપો.

દરેક પ્રથમ માટે 0 થી 3 સુધી આ ફરી કરો:
  દરેક બીજું માટે 0 થી 4 સુધી આ ફરી કરો:
    “ackermann(” પછી પ્રથમ પછી “, ” પછી બીજું પછી “) = ” પછી એકરમેન (પ્રથમ, બીજું) લખો અને લીટી પૂરી કરો.
