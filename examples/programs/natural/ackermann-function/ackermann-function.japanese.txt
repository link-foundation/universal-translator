注：Ackermann function in JavaScript, defined recursively

アッカーマン を 第一 と 第二 で 定義 する：
  もし 第一 が 0 に 等しい なら 次 を する：
    第二 足す 1 を 返す。
  もし 第二 が 0 に 等しい なら 次 を する：
    アッカーマン (第一 引く 1、 1) を 返す。
  アッカーマン (第一 引く 1、 アッカーマン (第一、 第二 引く 1)) を 返す。
