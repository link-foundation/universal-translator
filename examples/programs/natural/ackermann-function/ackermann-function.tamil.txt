குறிப்பு: Ackermann function in JavaScript, defined recursively

அக்கர்மன் ஐ முதலாவது மற்றும் இரண்டாவது கொண்டு வரையறு:
  ஒருவேளை முதலாவது மதிப்பு 0 க்கு சமம் என்றால் இதைச் செய்:
    இரண்டாவது கூட்டல் 1 திருப்பி அனுப்பு.
  ஒருவேளை இரண்டாவது மதிப்பு 0 க்கு சமம் என்றால் இதைச் செய்:
    அக்கர்மன் (முதலாவது கழித்தல் 1, 1) திருப்பி அனுப்பு.
  அக்கர்மன் (முதலாவது கழித்தல் 1, அக்கர்மன் (முதலாவது, இரண்டாவது கழித்தல் 1)) திருப்பி அனுப்பு.

ஒவ்வொரு முதலாவது க்கும் 0 முதல் 3 வரை இதை மீண்டும் செய்:
  ஒவ்வொரு இரண்டாவது க்கும் 0 முதல் 4 வரை இதை மீண்டும் செய்:
    “ackermann(” அதன் பின் முதலாவது அதன் பின் “, ” அதன் பின் இரண்டாவது அதன் பின் “) = ” அதன் பின் அக்கர்மன் (முதலாவது, இரண்டாவது) எழுதி வரியை முடி.
