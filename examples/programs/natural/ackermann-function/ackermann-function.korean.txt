참고: Ackermann function in JavaScript, defined recursively

아커만 을 첫째 및 둘째 로 정의한다:
  만약 첫째 이 0 과 같음 이면 다음을 한다:
    둘째 더하기 1 을 돌려준다.
  만약 둘째 이 0 과 같음 이면 다음을 한다:
    아커만 (첫째 빼기 1, 1) 을 돌려준다.
  아커만 (첫째 빼기 1, 아커만 (첫째, 둘째 빼기 1)) 을 돌려준다.

각 첫째 에 대해 0 부터 3 까지 다음을 반복한다:
  각 둘째 에 대해 0 부터 4 까지 다음을 반복한다:
    “ackermann(” 뒤에 첫째 뒤에 “, ” 뒤에 둘째 뒤에 “) = ” 뒤에 아커만 (첫째, 둘째) 을 쓰고 줄을 바꾼다.
