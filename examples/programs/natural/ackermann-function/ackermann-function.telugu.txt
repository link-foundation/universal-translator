గమనిక: Ackermann function in JavaScript, defined recursively

అకెర్మాన్ ను మొదటి మరియు రెండవ తో నిర్వచించు:
  ఒకవేళ మొదటి విలువ 0 కి సమానం అయితే ఇది చేయి:
    రెండవ కూడిక 1 తిరిగి ఇవ్వు.
  ఒకవేళ రెండవ విలువ 0 కి సమానం అయితే ఇది చేయి:
    అకెర్మాన్ (మొదటి తీసివేత 1, 1) తిరిగి ఇవ్వు.
  అకెర్మాన్ (మొదటి తీసివేత 1, అకెర్మాన్ (మొదటి, రెండవ తీసివేత 1)) తిరిగి ఇవ్వు.

ప్రతి మొదటి కి 0 నుండి 3 వరకు ఇది పునరావృతం చేయి:
  ప్రతి రెండవ కి 0 నుండి 4 వరకు ఇది పునరావృతం చేయి:
    “ackermann(” తర్వాత మొదటి తర్వాత “, ” తర్వాత రెండవ తర్వాత “) = ” తర్వాత అకెర్మాన్ (మొదటి, రెండవ) రాసి పంక్తి ముగించు.
