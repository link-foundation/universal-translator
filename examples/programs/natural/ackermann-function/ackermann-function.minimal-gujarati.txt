નોંધ: Ackermann function in JavaScript, defined recursively

કોઈ એકરમેન ને પ્રથમ અને બીજું સાથે આમ કરે છે:
  જો પ્રથમ એ 0 જેવું જ છે તો આ કરો:
    જવાબ બીજું વત્તા 1 છે.
  જો બીજું એ 0 જેવું જ છે તો આ કરો:
    જવાબ એકરમેન (પ્રથમ ઓછા 1, 1) છે.
  જવાબ એકરમેન (પ્રથમ ઓછા 1, એકરમેન (પ્રથમ, બીજું ઓછા 1)) છે.

દરેક પ્રથમ માટે 0 થી 3 સુધી આ કરો:
  દરેક બીજું માટે 0 થી 4 સુધી આ કરો:
    “ackermann(” પછી પ્રથમ પછી “, ” પછી બીજું પછી “) = ” પછી એકરમેન (પ્રથમ, બીજું) એક લીટીમાં કહો.
