टिप्पणी: Ackermann function in JavaScript, defined recursively

कोई पहला और दूसरा के साथ एकरमैन ऐसे करता है:
  अगर पहला वही है जो 0 है तो यह करें:
    जवाब है दूसरा जमा 1।
  अगर दूसरा वही है जो 0 है तो यह करें:
    जवाब है एकरमैन (पहला घटा 1, 1)।
  जवाब है एकरमैन (पहला घटा 1, एकरमैन (पहला, दूसरा घटा 1))।

हर पहला के लिए 0 से 3 तक यह करें:
  हर दूसरा के लिए 0 से 4 तक यह करें:
    “ackermann(” फिर पहला फिर “, ” फिर दूसरा फिर “) = ” फिर एकरमैन (पहला, दूसरा) एक पंक्ति में कहें।
