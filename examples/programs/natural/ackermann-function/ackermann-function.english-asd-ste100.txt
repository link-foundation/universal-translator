Note: Ackermann function in JavaScript, defined recursively

Procedure ackermann with first and second:
  If first equals 0, do these steps:
    Return second plus 1.
  If second equals 0, do these steps:
    Return ackermann of (first minus 1, 1).
  Return ackermann of (first minus 1, ackermann of (first, second minus 1)).

For each first from 0 to 3, do these steps:
  For each second from 0 to 4, do these steps:
    Write line “ackermann(” then first then “, ” then second then “) = ” then ackermann of (first, second).
