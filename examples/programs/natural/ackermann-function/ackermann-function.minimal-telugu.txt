గమనిక: Ackermann function in JavaScript, defined recursively

ఎవరో అకెర్మాన్ ను మొదటి మరియు రెండవ తో ఇలా చేస్తారు:
  ఒకవేళ మొదటి అనేది 0 తో అదే అయితే ఇది చేయి:
    జవాబు రెండవ కూడిక 1.
  ఒకవేళ రెండవ అనేది 0 తో అదే అయితే ఇది చేయి:
    జవాబు అకెర్మాన్ (మొదటి తీసివేత 1, 1).
  జవాబు అకెర్మాన్ (మొదటి తీసివేత 1, అకెర్మాన్ (మొదటి, రెండవ తీసివేత 1)).

అన్ని మొదటి కి 0 నుండి 3 వరకు ఇది చేయి:
  అన్ని రెండవ కి 0 నుండి 4 వరకు ఇది చేయి:
    “ackermann(” తర్వాత మొదటి తర్వాత “, ” తర్వాత రెండవ తర్వాత “) = ” తర్వాత అకెర్మాన్ (మొదటి, రెండవ) ను ఒక పంక్తిలో చెప్పు.
