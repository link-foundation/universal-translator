Note: Ackermann function in JavaScript, defined recursively

To get ackermann from first and second, do this:
  If first equals 0, do this:
    Return second plus 1.
  If second equals 0, do this:
    Return ackermann of (first minus 1, 1).
  Return ackermann of (first minus 1, ackermann of (first, second minus 1)).

For each first from 0 to 3, do this:
  For each second from 0 to 4, do this:
    Say “ackermann(” then first then “, ” then second then “) = ” then ackermann of (first, second) on a line.
