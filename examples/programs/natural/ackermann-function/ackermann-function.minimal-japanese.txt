注：Ackermann function in JavaScript, defined recursively

誰か が アッカーマン を 第一 と 第二 で こう する：
  もし 第一 が 0 と 同じ なら これ を する：
    答え は 第二 足す 1 だ。
  もし 第二 が 0 と 同じ なら これ を する：
    答え は アッカーマン (第一 引く 1、 1) だ。
  答え は アッカーマン (第一 引く 1、 アッカーマン (第一、 第二 引く 1)) だ。

全て の 第一 について 0 から 3 まで これ を する：
  全て の 第二 について 0 から 4 まで これ を する：
    「ackermann(」 それから 第一 それから 「, 」 それから 第二 それから 「) = 」 それから アッカーマン (第一、 第二) を 一つ の 行 に 言う。
