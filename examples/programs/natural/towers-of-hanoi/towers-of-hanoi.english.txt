Note: Towers of Hanoi in JavaScript, solved recursively

Define move-disks using count, source, target and spare:
  If count equals 0, do this:
    Stop here.
  Run move-disks of (count minus 1, source, spare, target).
  Write “Move disk ” followed by count followed by “ from ” followed by source followed by “ to ” followed by target and end the line.
  Run move-disks of (count minus 1, spare, target, source).

Run move-disks of (4, 1, 3, 2).
