નોંધ: Greatest element of a list in JavaScript

સંખ્યાઓ છે, તે આ વસ્તુઓ (17, 4, 93, 28, 65, 3, 80) છે.
મહત્તમ છે, તે સંખ્યાઓ માં ભાગ 0 છે.
દરેક અનુક્રમ માટે 0 થી સંખ્યાઓ માં કેટલા ભાગ ઓછા 1 સુધી આ કરો:
  સંખ્યા છે, તે સંખ્યાઓ માં ભાગ અનુક્રમ છે.
  જો સંખ્યા એ મહત્તમ કરતાં વધુ છે તો આ કરો:
    આ પછી મહત્તમ સંખ્યા છે.
“The greatest element is ” પછી મહત્તમ એક લીટીમાં કહો.
