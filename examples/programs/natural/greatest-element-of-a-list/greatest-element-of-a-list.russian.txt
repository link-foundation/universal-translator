Примечание: Greatest element of a list in JavaScript

Создать числа со значением список (17, 4, 93, 28, 65, 3, 80).
Создать наибольший со значением элемент 0 списка числа.
Для каждого индекс от 0 до длина числа минус 1 повторять это:
  Создать число со значением элемент индекс списка числа.
  Если число больше наибольшего, сделать это:
    Изменить наибольший на число.
Написать «The greatest element is » затем наибольший и закончить строку.
