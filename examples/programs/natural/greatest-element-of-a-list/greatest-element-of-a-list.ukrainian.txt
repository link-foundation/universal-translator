Примітка: Greatest element of a list in JavaScript

Створити числа зі значенням список (17, 4, 93, 28, 65, 3, 80).
Створити найбільший зі значенням елемент 0 списку числа.
Для кожного індекс від 0 до довжина числа мінус 1 повторювати це:
  Створити число зі значенням елемент індекс списку числа.
  Якщо число більше за найбільший, зробити це:
    Змінити найбільший на число.
Написати «The greatest element is » потім найбільший і завершити рядок.
