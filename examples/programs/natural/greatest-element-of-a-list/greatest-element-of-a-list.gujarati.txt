નોંધ: Greatest element of a list in JavaScript

સંખ્યાઓ ને કિંમત યાદી (17, 4, 93, 28, 65, 3, 80) સાથે બનાવો.
મહત્તમ ને કિંમત સંખ્યાઓ માં ઘટક 0 સાથે બનાવો.
દરેક અનુક્રમ માટે 0 થી સંખ્યાઓ ની લંબાઈ ઓછા 1 સુધી આ ફરી કરો:
  સંખ્યા ને કિંમત સંખ્યાઓ માં ઘટક અનુક્રમ સાથે બનાવો.
  જો સંખ્યા નું મૂલ્ય મહત્તમ કરતાં વધુ છે તો આ કરો:
    મહત્તમ ને સંખ્યા માં બદલો.
“The greatest element is ” પછી મહત્તમ લખો અને લીટી પૂરી કરો.
