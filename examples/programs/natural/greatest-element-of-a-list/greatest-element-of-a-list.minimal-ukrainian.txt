Примітка: Greatest element of a list in JavaScript

Є числа, це ці речі (17, 4, 93, 28, 65, 3, 80).
Є найбільший, це частина 0 з числа.
Для всіх індекс від 0 до скільки частин має числа мінус 1, зробити це:
  Є число, це частина індекс з числа.
  Якщо число більше ніж найбільший, зробити це:
    Після цього найбільший є число.
Сказати «The greatest element is » потім найбільший в одному рядку.
