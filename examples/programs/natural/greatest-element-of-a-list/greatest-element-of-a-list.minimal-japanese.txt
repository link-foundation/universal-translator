注：Greatest element of a list in JavaScript

数列 が ある、 それ は これら の もの (17、 4、 93、 28、 65、 3、 80) だ。
最大 が ある、 それ は 数列 の 部分 0 だ。
全て の 添字 について 0 から 数列 の 部分 の 数 引く 1 まで これ を する：
  数_ が ある、 それ は 数列 の 部分 添字 だ。
  もし 数_ が 最大 より 多い なら これ を する：
    この 後 最大 は 数_ だ。
「The greatest element is 」 それから 最大 を 一つ の 行 に 言う。
