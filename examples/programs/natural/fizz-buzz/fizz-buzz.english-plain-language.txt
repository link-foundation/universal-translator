Note: FizzBuzz in JavaScript

For each number from 1 to 100, do this:
  If number modulo 15 is 0, do this:
    Show “FizzBuzz” on its own line.
  If not, but number modulo 3 is 0, do this:
    Show “Fizz” on its own line.
  If not, but number modulo 5 is 0, do this:
    Show “Buzz” on its own line.
  If not, do this:
    Show number on its own line.
