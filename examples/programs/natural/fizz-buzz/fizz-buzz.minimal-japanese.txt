注：FizzBuzz in JavaScript

全て の 数_ について 1 から 100 まで これ を する：
  もし 数_ 剰余 15 が 0 と 同じ なら これ を する：
    「FizzBuzz」 を 一つ の 行 に 言う。
  そう で ない なら もし 数_ 剰余 3 が 0 と 同じ なら これ を する：
    「Fizz」 を 一つ の 行 に 言う。
  そう で ない なら もし 数_ 剰余 5 が 0 と 同じ なら これ を する：
    「Buzz」 を 一つ の 行 に 言う。
  そう で ない なら これ を する：
    数_ を 一つ の 行 に 言う。
