注：Leap year in JavaScript

誰か が 判定-閏-年 を 年 で こう する：
  答え は 年 剰余 4 が 0 と 同じ かつ 年 剰余 100 が 0 と 違う または 年 剰余 400 が 0 と 同じ だ。

全て の 年 について 1896 から 1912 まで これ を する：
  もし 判定-閏-年 (年) なら これ を する：
    年 それから 「 is a leap year」 を 一つ の 行 に 言う。
  そう で ない なら これ を する：
    年 それから 「 is not a leap year」 を 一つ の 行 に 言う。
