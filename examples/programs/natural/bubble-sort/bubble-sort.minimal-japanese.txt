注：Bubble sort in JavaScript: sort a list of numbers

数列 が ある、 それ は これら の もの (5、 3、 8、 1、 9、 2、 7) だ。
個数 が ある、 それ は 数列 の 部分 の 数 だ。
全て の 巡 について 0 から 個数 引く 1 引く 1 まで これ を する：
  全て の 添字 について 0 から 個数 引く 1 引く 巡 引く 1 まで これ を する：
    もし 数列 の 部分 添字 が 数列 の 部分 (添字 足す 1) より 多い なら これ を する：
      交換 が ある、 それ は 数列 の 部分 添字 だ。
      この 後 数列 の 部分 添字 は 数列 の 部分 (添字 足す 1) だ。
      この 後 数列 の 部分 (添字 足す 1) は 交換 だ。
全て の 位置 について 0 から 個数 引く 1 まで これ を する：
  数列 の 部分 位置 を 一つ の 行 に 言う。
