Примечание: Bubble sort in JavaScript: sort a list of numbers

Есть числа, это эти вещи (5, 3, 8, 1, 9, 2, 7).
Есть количество, это сколько частей в числа.
Для всех проход от 0 до количество минус 1 минус 1 делать это:
  Для всех индекс от 0 до количество минус 1 минус проход минус 1 делать это:
    Если часть индекс из числа больше часть (индекс плюс 1) из числа, сделать это:
      Есть обмен, это часть индекс из числа.
      После этого часть индекс из числа будет часть (индекс плюс 1) из числа.
      После этого часть (индекс плюс 1) из числа будет обмен.
Для всех позиция от 0 до количество минус 1 делать это:
  Сказать часть позиция из числа на одной строке.
