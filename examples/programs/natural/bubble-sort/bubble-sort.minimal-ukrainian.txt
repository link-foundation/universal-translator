Примітка: Bubble sort in JavaScript: sort a list of numbers

Є числа, це ці речі (5, 3, 8, 1, 9, 2, 7).
Є кількість, це скільки частин має числа.
Для всіх прохід від 0 до кількість мінус 1 мінус 1, зробити це:
  Для всіх індекс від 0 до кількість мінус 1 мінус прохід мінус 1, зробити це:
    Якщо частина індекс з числа більше ніж частина (індекс плюс 1) з числа, зробити це:
      Є обмін, це частина індекс з числа.
      Після цього частина індекс з числа є частина (індекс плюс 1) з числа.
      Після цього частина (індекс плюс 1) з числа є обмін.
Для всіх позиція від 0 до кількість мінус 1, зробити це:
  Сказати частина позиція з числа в одному рядку.
