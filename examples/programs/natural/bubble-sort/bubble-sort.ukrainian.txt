Примітка: Bubble sort in JavaScript: sort a list of numbers

Створити числа зі значенням список (5, 3, 8, 1, 9, 2, 7).
Створити кількість зі значенням довжина числа.
Для кожного прохід від 0 до кількість мінус 1 мінус 1 повторювати це:
  Для кожного індекс від 0 до кількість мінус 1 мінус прохід мінус 1 повторювати це:
    Якщо елемент індекс списку числа більше за елемент (індекс плюс 1) списку числа, зробити це:
      Створити обмін зі значенням елемент індекс списку числа.
      Змінити елемент індекс списку числа на елемент (індекс плюс 1) списку числа.
      Змінити елемент (індекс плюс 1) списку числа на обмін.
Для кожного позиція від 0 до кількість мінус 1 повторювати це:
  Написати елемент позиція списку числа і завершити рядок.
