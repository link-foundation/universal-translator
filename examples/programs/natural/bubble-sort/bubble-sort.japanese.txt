注：Bubble sort in JavaScript: sort a list of numbers

数列 を 値 リスト (5、 3、 8、 1、 9、 2、 7) で 作る。
個数 を 値 数列 の 長さ で 作る。
巡 を 0 から 個数 引く 1 引く 1 まで 数えて 次 を 繰り返す：
  添字 を 0 から 個数 引く 1 引く 巡 引く 1 まで 数えて 次 を 繰り返す：
    もし 数列 の 要素 添字 が 数列 の 要素 (添字 足す 1) より 大きい なら 次 を する：
      交換 を 値 数列 の 要素 添字 で 作る。
      数列 の 要素 添字 を 数列 の 要素 (添字 足す 1) に 変える。
      数列 の 要素 (添字 足す 1) を 交換 に 変える。
位置 を 0 から 個数 引く 1 まで 数えて 次 を 繰り返す：
  数列 の 要素 位置 を 書いて 改行 する。
