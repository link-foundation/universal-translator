Note: Bubble sort in JavaScript: sort a list of numbers

Let numbers start as the list (5, 3, 8, 1, 9, 2, 7).
Let count start as the length of numbers.
For each pass from 0 to count minus 1 minus 1, do this:
  For each index from 0 to count minus 1 minus pass minus 1, do this:
    If item index of numbers is more than item (index plus 1) of numbers, do this:
      Let swap start as item index of numbers.
      Set item index of numbers to item (index plus 1) of numbers.
      Set item (index plus 1) of numbers to swap.
For each position from 0 to count minus 1, do this:
  Show item position of numbers on its own line.
