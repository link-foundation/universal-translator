참고: Bubble sort in JavaScript: sort a list of numbers

수들 을 값 목록 (5, 3, 8, 1, 9, 2, 7) 로 만든다.
개수 을 값 수들 길이 로 만든다.
각 회차 에 대해 0 부터 개수 빼기 1 빼기 1 까지 다음을 반복한다:
  각 색인 에 대해 0 부터 개수 빼기 1 빼기 회차 빼기 1 까지 다음을 반복한다:
    만약 수들 원소 색인 이 수들 원소 (색인 더하기 1) 보다 큼 이면 다음을 한다:
      교환 을 값 수들 원소 색인 로 만든다.
      수들 원소 색인 을 수들 원소 (색인 더하기 1) 로 바꾼다.
      수들 원소 (색인 더하기 1) 을 교환 로 바꾼다.
각 위치 에 대해 0 부터 개수 빼기 1 까지 다음을 반복한다:
  수들 원소 위치 을 쓰고 줄을 바꾼다.
