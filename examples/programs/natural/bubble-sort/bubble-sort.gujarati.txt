નોંધ: Bubble sort in JavaScript: sort a list of numbers

સંખ્યાઓ ને કિંમત યાદી (5, 3, 8, 1, 9, 2, 7) સાથે બનાવો.
ગણતરી ને કિંમત સંખ્યાઓ ની લંબાઈ સાથે બનાવો.
દરેક ફેરો માટે 0 થી ગણતરી ઓછા 1 ઓછા 1 સુધી આ ફરી કરો:
  દરેક અનુક્રમ માટે 0 થી ગણતરી ઓછા 1 ઓછા ફેરો ઓછા 1 સુધી આ ફરી કરો:
    જો સંખ્યાઓ માં ઘટક અનુક્રમ નું મૂલ્ય સંખ્યાઓ માં ઘટક (અનુક્રમ વત્તા 1) કરતાં વધુ છે તો આ કરો:
      અદલાબદલી ને કિંમત સંખ્યાઓ માં ઘટક અનુક્રમ સાથે બનાવો.
      સંખ્યાઓ માં ઘટક અનુક્રમ ને સંખ્યાઓ માં ઘટક (અનુક્રમ વત્તા 1) માં બદલો.
      સંખ્યાઓ માં ઘટક (અનુક્રમ વત્તા 1) ને અદલાબદલી માં બદલો.
દરેક સ્થાન માટે 0 થી ગણતરી ઓછા 1 સુધી આ ફરી કરો:
  સંખ્યાઓ માં ઘટક સ્થાન લખો અને લીટી પૂરી કરો.
